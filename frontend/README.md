# Medicine Challenge Frontend

This is a Next.js application that displays medicine program information.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- Yarn package manager

### Installation

1. Install dependencies:
```bash
yarn install
```

### Development

To run the development server:

```bash
yarn dev
```

The application will be available at [http://localhost:3000](http://localhost:3000).

## Available Routes

- **Home Page**: [http://localhost:3000](http://localhost:3000)
  - Displays the main dashboard

- **Program Details**: [http://localhost:3000/programs/11757](http://localhost:3000/programs/11757)
  - Shows detailed information for a specific program

## Built With

- [Next.js](https://nextjs.org/) - The React Framework for Production
- [React](https://reactjs.org/) - A JavaScript library for building user interfaces
